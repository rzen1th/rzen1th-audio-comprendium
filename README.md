# rzen1th-general-foley
A completely free audio library!
This repository contains every sound effect I have made (that I own the rights to) to date. All of the SFX in this repository were recorded and/or designed by myself. For personal use, you do not have to ask me permission to do whatever you want with these sounds. With certain explicit exceptions, the contents of this library are completely free to download, use, and modify for any NON-PROFIT or NON-COMMERCIAL project; just be sure to credit and leave me (rzen1th) listed as an author in the file metadata. Have fun!
